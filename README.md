## [Slashblade: Refabricated](https://modrinth.com/mod/slashblade-refabricated) Unique ID Edition

SlashBlade: Resharped unofficial Fabric port.

The swords from the original mod have been split into separate IDs, ensuring each sword now possesses its own unique item ID (facilitating editing for FTB or HBM tasks on versions 1.21+).

# The original mod's add-ons have undergone the same restructuring, but they are now exclusive to this mod and incompatible with the original version.
https://github.com/Rxstar-sq/SlashBladeFabricAddons/tree/1.21.1_addon_new

## How to Build
Open the project root directory in the address bar of File Explorer or via PowerShell.
Navigate to the repository directory.
Build:
.\gradlew.bat build
or
.\gradlew.bat clean build

Jar output: Located in build/libs/
