# SlashBlade: Refabricated  

SlashBlade: Resharped unofficial Fabric port.

## 拔刀剑重织的重做调整版本

将原本模组的的刀进行了id分割，让所有的刀都有自己独有的物品id（方便对1.21+版本的ftb或者HBM任务编辑）

# 对于原模组的附属也进行了相同的重构，但是只能与这个模组一起使用，无法兼容原本的模组了
https://github.com/Rxstar-sq/SlashBladeFabricAddons/tree/1.21.1_addon_new

## 如何构建
在资源管理器地址栏或 PowerShell 打开项目根目录
进入仓库目录
构建：
.\gradlew.bat build
或
.\gradlew.bat clean build

Jar 输出: 位于 build/libs/ 内
